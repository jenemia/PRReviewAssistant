## 새로운 기능

- 새 리뷰가 들어오면 분류된 코멘트를 에이전트가 자동으로 검토합니다. 설정에서 자동 검토를 끌 수 있으며 기본값은 켜짐입니다.
- 같은 저장소에서 다른 PR이 활성화된 경우 작업 폴더 전환을 승인한 뒤 검토할 수 있습니다.

## 개선 사항

- 역할별 코드 검토 결과에 판단 근거와 대응 계획을 더 명확하게 표시하고 권한 요청과 실패 상황을 안내합니다.
- 작업 요청에 사용자의 추가 조건을 반영하고, 실제 커밋을 바탕으로 코멘트별 재리뷰 요약을 작성합니다.
- 리뷰 카드 전환 시 화면 폭을 유지하고 PR 요청과 머지 화면을 개선했습니다.
